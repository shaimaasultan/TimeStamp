# TimeStamp
📁 File Timestamp Range Filter

  Filter and display files modified within a specific timestamp range using forensic-grade logic. Designed for browser-based environments with independent entity handling for folders and subfolders.
<img src="Screenshot 2025-10-18 165154.png"/>

---
🔍 Features

  ✅ Filters files by their own last modified timestamp

  📂 Treats folders as independent entities, not inherited from subfiles

  🧪 Modular timestamp logic for reproducibility and edge-case accuracy

  🖥️ Visual output includes filename, timestamp, size, type, and full path

  🔧 Supports search by filename, date, size, type, and path

🧰 Setup
  Clone the repo
  
  Open TimeStamp.html in your browser
  
  Ensure timestampfilter.js is linked and error-free
  
  Adjust timestamp range in the script as needed

🧠 Forensic Notes
  Subfolders are not recursively scanned—each folder is timestamped independently
  
  Timestamp logic is modular and reproducible for forensic validation
  
  Designed to support teaching tools and edge-case exploration
